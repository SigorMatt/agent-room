## Scope

The focus diff stays within the fixes for R3-1 to R3-8. It makes no change outside their files' purpose, apart from qodo fetch 4 records and dispositions. The code changes are small and covered by tests: the watchdog role leaves `start-lead` and `WATCHDOG_CAN`, `state unreadable` gets its reminder, the S2-5 test is restored, and dead code goes. All seven suites pass (`for t in tests/test_*.py …`: no `FAILED`). Mutations of the R3-3 and R3-4 code each fail test_relay. The protocol fixes add cases rather than rework flows. The ARCHITECT.md 9.5 case for a `LEAD-STARTED` that never came online fits the existing 30-minute rule. The new rules have gaps at their edges. Join step 7's applied test isn't tied to the decision it judges (S4-1). The `state unreadable` reminder skips the failed-buzz retry and is missing from the architect's protocol (S4-2, S4-3). The pre-park buzz retry fails for the daily limit it was written for, buzzes under a kind the manuals call no-action, and is bypassed by 5.6's hold text (S4-4 to S4-6). One small mislabel: the spec tags the `state unreadable` reminder line "(cold R3-5)", but the finding is R3-4.
